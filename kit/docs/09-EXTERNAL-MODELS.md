# External models / Modelos externos — AGPL-3.0-only core

The plugin's original code remains AGPL-3.0-only. Model artifacts are separately obtained and never included in this distribution. A model's license, model code, tokenizer, training-material rights and notices must be reviewed at its exact revision; a model card label or a self-declared manifest is not a legal guarantee. Do not use any model with conditions incompatible with the intended combination/distribution. This gate is deliberately conservative and is not a ruling that every other license is incompatible. Do not add proprietary, noncommercial or field-of-use restrictions to the AGPL-covered code. See https://www.gnu.org/licenses/license-compatibility.en.html and https://www.gnu.org/licenses/gpl-faq.html.

## Candidate models (metadata only, not validated inference)

- `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`: provider declares Apache-2.0, safetensors available: https://huggingface.co/sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2. Suggested first candidate for mixed languages.
- `intfloat/multilingual-e5-small`: provider declares MIT, safetensors available: https://huggingface.co/intfloat/multilingual-e5-small. E5 retrieval has model-specific query/document prefixes; integration quality has not been tested. Do not claim benchmark or compatibility without checking.

## Setup (trusted local executor only)

1. Choose a specific revision; inspect upstream license, rights, notices, file paths and configuration. Download only necessary standard Transformer, Pooling and Normalize modules, tokenizers, configuration and `.safetensors` weights into a new private directory. Keep the full upstream license and required notices. Do not copy repository Python, pickled `.bin` weights, custom modules, symlinks, hidden cache folders or unrelated formats. Do not point to a shared writable directory. The plugin does not fetch models from the network.
2. Create `reveritrace-model.json` inside that directory, independently verifying the publisher's hashes where available. The following is a schema illustration, not a usable manifest: `{"source":"<HTTPS upstream URL>","revision":"<exact revision>","license":"Apache-2.0","license_url":"<HTTPS original license URL>","rights_reviewed":true,"sha256":{"config.json":"<64 lowercase hex digits>","model.safetensors":"<64 lowercase hex digits>"}}`. Include an entry for EVERY file other than the manifest, with relative POSIX paths. `rights_reviewed` is your statement, not an automatic certification. Compute hashes using `python -c "import hashlib,pathlib; p=pathlib.Path('FILE'); print(hashlib.file_digest(p.open('rb'),'sha256').hexdigest())"` on Python 3.11+. On older Python use `hashlib.sha256` on file chunks. Verify originals before hashing; a local hash cannot establish provenance.
3. Install the optional runtime `sentence-transformers` into a separate virtual environment after reviewing current dependency advisories and licenses. Use supported Python, trusted packages and a reproducible platform-specific lock file. Do not distribute the environment or weights with the plugin unless every applicable source/license/notice obligation is satisfied. No third-party packages are bundled. Run the CLI with `python history.py --db INDEX search --query "..." --model /path/to/model` (or `configure --model` to persist the path). No external inference API is called. `--semantic off` disables neural and LSA execution even if a saved model exists.
4. Admission blocks unknown/restricted license labels, missing review/provenance, altered files, symlinks, unsafe file extensions, custom modules, outside paths and dynamic code maps. Accepted license identifiers: `Apache-2.0`, `MIT`, `BSD-2-Clause`, `BSD-3-Clause`, `CC0-1.0`, `AGPL-3.0-only`, `AGPL-3.0-or-later`. The backend uses `local_files_only=True`, `trust_remote_code=False`, `use_safetensors=True`, CPU / Torch. Rejected models fall back to LSA or lexical search. Validation is defense in depth, not a sandbox or license oracle: malicious artifacts, resource exhaustion, TOCTOU, runtime and dependency vulnerabilities remain possible. Do not run untrusted models; use OS-level isolation/network denial for stronger guarantees. No real model-inference test was run in this build.

## Remote models

No external model API is implemented in this release. A future remote connector must be clearly separate, explicitly opt-in, use minimum necessary data, disclose recipient and retention, and honor provider terms, data protection and AGPL requirements. Do not send private history to external services without consent. No proprietary-only changes to the covered program may be distributed in violation of AGPL. Whether components form a combined work is contextual; architectural separation alone does not guarantee compliance.
