# Security and license review — v1.0.1

Read source files for history indexing, semantic ranking, incremental import, archive comparison, skill, manifest, notices and website drafts. Corrected non-YouTube URL acceptance, tracking/redirect links, archive path traversal, direct symlink imports, silent rejected-row count on repeat, disabled engine override, and unsafe external model admission. Residual risks: user-provided titles are untrusted data, not instructions; local DB is plaintext; huge history can consume CPU/RAM; model and dependency supply chain vulnerabilities cannot be eliminated by checksums alone; full account isolation requires separate verified local inboxes and DBs; a user-supplied account label is not authentication. No penetration test, dependency CVE scan, full transitive license audit, external model inference, OAuth, or marketplace execution was completed. Do not guarantee absence of vulnerabilities or legal compliance. Public distribution still requires permission to license all original assets, actual publisher, published policy/support/site/terms as applicable, OpenAI review and required attestations. No real user data used in generated test fixtures.
